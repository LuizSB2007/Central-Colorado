# Central-Colorado
República Colorado é um aplicativo web (PWA) feito sob medida para a gestão e convivência interna da casa. Ele automatiza a escala de limpeza circular, organiza a lista de compras e eventos, mantém um mural de avisos atualizado e traz o Babálorado, um sistema gamificado de ranking e punições com fotos para movimentar a resenha da república.
